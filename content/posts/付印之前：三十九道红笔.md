十一月十日中午，屏幕上并排放着两张截图。

左边那张，右下角两颗球一上一下叠着；右边那张，它们各占一边，圆的那颗往左挪了一个拳头宽，扁的那颗补在它右边。我在触控板上来回滑了七八次，最后停在右边那张，起身去接水。杯子是早上倒的，已经凉透了。

那天后来又切了很多次截图。到夜里整理的时候，改动记录写到了第三十九节。

![付印之前](/img/rebirth/01-cover.webp)

## 一张还没付印的纸

桌上还摊着一张 A4，是这套站点的色卡。最上面一格 `#f4f1ea`，偏暖的书页白；往下 `#16130f`，几乎黑；再往下 `#d9431f`，朱砂。三格之间没有渐变，像印厂送来让人挑纸样的小卡片，边角还留着裁纸刀的毛边。

字分三套。标题用系统黑体，一个字节都不用下载；正文是一份霞鹜文楷，站点说话的声音；日期、编号、字数交给等宽字体记账。字号不是写死的，从 360 到 1440 之间用 `clamp()` 插值，最小 `0.72rem`，最大 `7.2rem`，中间交给浏览器自己算。

再往下是尺子。目录页外壳 1200px，正文栏 980px，宽屏右侧还要匀出约 160px 的通道放章节目录。首页刊头是 8fr 比 4fr，头条栏是 7fr 比 5fr。这些数字后来在同一天里被量了很多遍，尺子就搁在键盘右边。

![色卡、字阶与栏宽](/img/rebirth/02-system.svg)

同一件事在纸上叫版式，在代码里叫令牌。调墨的时候，纸还是空的。

## 上午：把「在后面」摆平

八点多，站名后面那个点还是五乘五的点阵，会按栏目变成圆、方、三角、弧、十字。顶栏 14px，刊头 `.19em`，落款 8px，三处共用一副骨架。那天先把它换成一枚实心朱砂圆，三处一起换。

同一个品牌原子不该有两种形态。

接着加一颗球。参考文件里躺着三个场景：潮汐之境已经搬进刊头，风起沙丘还在，夜航星海是第三个——22000 个点、四条对数旋臂、倾斜盘面投影。搬过来压到 1800 点，角度抖动从 `gauss*(.22+r*.32)` 收到 `(.13+r*.18)`，背景星尘 20% 降到 12%，核心半径 `.12` 改 `.09`，中心晕的透明度 `.1` 改 `.08`。参数不改，旋臂会散成一团雾。

然后出了件小事。需求写的是「紧随其后并排两颗」，我做成了上下竖排——把「后面」当成阅读顺序，而他要的是同一行左右相邻。右栏 5fr，1440 视口下约 470px；两颗各 168px，加间距约 360px，其实放得下。改成一行之后，圆的那颗自然左移约 190px，刊头从 350px 矮到 168px。

![两颗球的位置](/img/rebirth/03-orbs.svg)

那杯凉水就是这时候接的。

## 中午：一个标题差了 7.5%

首页头条的标题「2026：在加速的时代，做一个清醒的慢行者」，第一行只放到「在加速的时代，」，右边空着一大片。看起来像是排版偷懒，其实是 `text-wrap: balance` 在替读者做主：它会主动把断点提前，好让两行长度接近。

换成 `pretty`，第一行倒是填满了，第二行只剩「行者」两个字。

拿尺子量了一遍。1440 视口下，标题容器 762px，字号 41.6px，整行文字 807px——差 45px，合 7.5%。把字号挂回令牌，写成 `calc(var(--step-3) * .9)`，落到 37.4px；1100、1280、1440 三档再量，都是一行。

![标题宽度：762 与 807](/img/rebirth/04-title-width.svg)

校样上的第一道红笔，不是把字改小，是先把尺寸量准。

下午又为标题返了一次工。阅读页有篇长文章，标题四十来字，第一行顶到右侧的点线目录，第二行只剩「化轨迹」。根因是前一轮为了让短标题一行放得下，把 `max-width` 一路放到 `100%`，等于按扉页全宽 1200px 排字；可正文栏是 `--rd-measure`，宽屏时 `min(980px, 100vw - 26rem)`，早就替目录留好了通道，两者差 220px。改回 `min(var(--rd-measure), 100%)` 之后，1440 / 1280 / 1100 三档标题宽 980 / 864 / 684，与正文栏左右边界差 0，距目录稳定 24px。折行策略也从 `pretty` 调回 `balance`：标题是居中的，两行配平比首行填满更经看。

同一处毛病，在左对齐的头条和居中的扉页里，得用两种药。

## 下午：扉页瘦了一圈

阅读页翻开是一张扉页。原来的样子是：眉题两条短线夹着分类，标题，两行摘要，一张被横线框住的账页，最下面一条 2px 的纯墨线，中间落一枚朱砂点。

摘要先下线。标题字号回调到 38.4px，扉页上下的留白、装饰线的宽度一并收。

账页是最占地方的一块。「写于」「篇幅」「阅读」「章节」四个词在上排，日期、字数、分钟数在下排，上下各一条 1px 线，右边还杵着一个 44px 的圆形 Aa 按钮。改成「写于 2026年2月17日 早上　篇幅 2,387 字」这样每项一行，框线和内边距全撤，字号统一降一档，Aa 缩到 32px，整块只剩一行高。

![扉页：两行账页与一行账页](/img/rebirth/05-head-before-after.webp)

窄屏还埋着一段旧规矩：767px 以下用 sr-only 把标签藏掉，又加回 `.7rem` 内边距，结果手机上只剩一串没有名字的数字。改组件排布时，得把同一个文件里所有媒体查询都搜一遍，旧断点常会把新样式悄悄按回去。

那天下午的截图里，正文比先前早出现了小半个屏幕。

## 傍晚：正文里的字距

字距是这轮最不容易被看见、也最影响读下去的东西。

旧的正文用 `text-align: justify` 加 `text-justify: inter-character`，中文逐字拉伸，每行都严丝合缝地顶到右边，字与字之间却忽宽忽窄。`strong` 直接刷成朱砂色，一整段一整段地红，满屏都是重点。霞鹜文楷笔画细，继承来的字号又偏小，整页看上去发灰。旧版 markdown 样式还漏了几样东西进来：行内代码前后各挂一个反引号，链接前面插站点图标，代码块右侧竖着写语言名，表头压着一层旧底色。

字体没换。用户说得很直白：整体用霞鹜文楷，项目里已经有了。于是动的是别的地方——18px 字号、1.85 行距、1.05em 段距，左对齐、`text-justify: auto`、`hyphens: none`。墨色分四级：正文 `#2c2721`，标题 `#16130f`，引文 `#4c463e`，图注 `#6a6257`。加粗改成深墨加一道极淡的朱砂底线，着重号用 CSS 的 `text-emphasis: filled dot`，落在字的下面，比斜体更贴楷体。分隔线是一条细线，正中间压一枚朱砂点。

![正文：拉伸的字距与朱砂强调，改成左对齐与四级墨色](/img/rebirth/06-prose-before-after.webp)

引用块单独返了一次工。我把旧版的弯引号 `“` 换成了 `「`，这个字符在横排楷体里就是一个直角折角，像个没画完的框；为了给它腾位置还留了 `2.6em` 左内边距，文字被推到右边。最后把字符整个撤掉，只留左侧 1px 朱砂细线，线头落一枚 7px 的实心圆点。

![引用块：直角折角与线头一点](/img/rebirth/07-quote-before-after.webp)

一枚点能顶替一个引号，是这天里我最喜欢的一笔。

## 夜里：一张卡片为什么没换

天黑之后处理的是别人看不见的部分。

结构化数据原本是手拼的字符串。`keywords` 的循环每项后面都带逗号，生成 `["a","b",]` 这种不合法的 JSON，整段会被搜索引擎直接丢掉；首页、归档、关于页全被标成 `BlogPosting`；`@context` 写的是 `http`；`mainEntityOfPage` 永远指向首页。改成用 `dict` 拼、`jsonify` 输出，按页面类型分流：首页 `WebSite`、文章 `BlogPosting`、独立页 `WebPage`、列表 `CollectionPage`。

`robots.txt` 末尾写着 `User-agent: * / Disallow: /`，把没列名的爬虫全挡在门外，微信、QQ、知乎的分享预览也一起挡了。改成默认放行，只单独拦 AI 爬虫。桌面浏览器上「分享」按钮原本只在系统分享接口存在时才显示，等于大多数时候没有；现在桌面点一下，会复制一段「标题 + 摘要 + 链接」的文案。

最后是一张图。分享卡已经重画过：1200×630，纸色底，黑体「一点」，后面一枚实心朱砂点，下面一行主张。文件也换了内容，可 X 里贴出来的还是一张黑底骷髅插画。

抓线上看了看，meta 全是新的，`twitter:card` 也是大图卡。问题在两处缓存：X 按图片 URL 记卡片，地址从头到尾都是 `/img/header.png`，它不会为同一个地址回来第二趟；`_headers` 又给 `/img/*` 设了 30 天缓存，响应头里 `max-age=0, must-revalidate` 和 `max-age=2592000` 两个值叠在一起。

一张卡片换了内容，平台却还认得它的旧门牌。

于是给图换了个地址：`/share/og-card-v2.png`。新目录不匹配 `/img/*`，只受全站 `max-age=0` 的兜底；文件名里带版本号，以后换卡片就递增 v3、v4。推送后复查，线上 `og:image` 已经是新地址，图片 `HTTP/2 200`，响应头只剩 `must-revalidate`。

已经发出去的旧推文不会变。那边的图被平台转存过，得用带 `?v=2` 的新链接发一条，或者让卡片校验器重抓一次。

![从 V10 到 V10.25](/img/rebirth/09-timeline.svg)

## 红笔里有一半是划掉的

编年写到这儿，会发现改动不全是「加」。

侠客整页撤了：`content/xiake.md`、三个旧别名、友链卡片样式、两个短代码副本、默认 favicon 图、一份没人引用的 JSON 数据，连同页脚入口、文档里的四处说明、注释里的三处名字。应用栏目早一步下线。站名后面那套会变形的点阵形状停用了，文件留着但零引用。账页的上下框线、扉页的简介、正文里满屏的朱砂、2px 的纯墨粗线、引用块的折角引号，一样一样划掉。

构建产物从 203 页、316 个文件，走到 202 页、311 个，最后因为多了一张分享卡变成 312。首页 HTML 从 40.6KB 到 47.5KB，样式表 152.8KB 到 155.7KB，gzip 之后多不到 1KB。

删文件像从书架上抽书，抽走之后，剩下的书脊才看得清。

![夜里的第二张校样](/img/rebirth/10-night.webp)

## 四层规矩

把这些红笔摊开看，它们其实落在四层上，每层各管一段。

**令牌层**管颜色、字号、间距。明暗两套主题只换变量的值，不换结构：`--paper` 明色 `#f4f1ea`、暗色 `#12110e`；`--zhu` 明色 `#d9431f`、暗色 `#ff5b36`。所以改一条引用块的线，不需要为深色再写一遍。字号优先挂在 `--step-N` 上用 `calc()` 缩放，而不是另写一个 `clamp()`——新数值越多，纸面越容易走形。

**网格层**管东西放在哪儿。`--rd-measure` 是已经扣掉右侧目录通道的正文宽度，标题、正文、图片都该跟着它；首页 8fr / 4fr 与头条栏 7fr / 5fr 各自独立，右栏 470px 容得下两颗 168px 的球和它们的间距。宽度一但写成 `100%`，就等于把父容器当成了版心，超出的那 220px 迟早会从标题的折行里冒出来。

**内容层**管机器读到的东西。描述按 `Params.description → Description → Summary → 站点描述` 依次取，纯文本化后截到 160 字；分享图只认显式写的 `og_image` / `banner`，不再猜正文第一张插图；结构化数据用 `jsonify`，不手拼带尾逗号的字符串。

**缓存层**管多久之后别人能看到。带内容指纹的 CSS / JS 可以缓存一年，`/img/*` 给 30 天，HTML 和分享图必须每次回源校验。文件内容和文件地址是两件事，平台记的是后者。

![四层：令牌、网格、内容、缓存](/img/rebirth/08-layers.svg)

校样上的红笔，最后得变成印版上不用再商量的尺寸。

后来 `static/fonts/` 里那份 681KB 的文件也被拿走了，正文换上系统宋体，屏幕上又少了一个请求。上面写楷体的地方，记的都是那天的纸。

尺子还搁在键盘右边，只是上面多贴了几道胶带。

关掉编辑器之前，我把最开始那两张截图又并排摆了一次。左边那版的两颗球还叠着，右边那版已经各占一边。构建日志停在 312 个文件上，最后一行是那张 1200×630 的纸：两个黑字，一枚朱砂点，比白天调的那个大了七倍。

它还没被任何人分享过。
